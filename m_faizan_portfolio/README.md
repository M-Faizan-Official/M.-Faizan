# M. Faizan Portfolio

Static responsive portfolio built with HTML, CSS, and JavaScript. No build step required.

## Add your images
Place these three images inside the `assets` folder (keep the exact filenames):
- `propic.png` — your portrait for the hero section.
- `project1.png` — Flappy Adventure screenshot.
- `project2.png` — DocuNest screenshot.

The logo and favicon are already included as `assets/faizan-logo.png` and `assets/favicon.png`.

Open `index.html` directly or use VS Code Live Server.
